One-line: the brand's only icon primitive — a Lucide glyph at 1.75 stroke weight; never emoji.

```jsx
<Icon name="shield-check" size={18} color="var(--signal-verified)" />
```

Requires the Lucide UMD script on the page. Sizes in use: 14 (dense chips), 16 (buttons, nav), 18–20 (cards), 24 (feature tiles).
