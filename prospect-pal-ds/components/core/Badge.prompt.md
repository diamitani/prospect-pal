One-line: small status/metadata chip; `deep` tone for navy surfaces, `mono` for machine values.

```jsx
<Badge tone="verified" icon="check">Verified contact</Badge>
<Badge tone="neutral" mono shape="square">ENV:CLAY_API_KEY</Badge>
```

Run statuses map to tones: draft→neutral, needs-clarification→attention, approved→verified, blocked→blocked.
