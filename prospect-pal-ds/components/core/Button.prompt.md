One-line: the action control — navy `primary` for most work, cobalt `accent` reserved for conversion/compile moments.

```jsx
<Button variant="accent" size="lg" icon="zap">Compile GTM Engine</Button>
<Button variant="outline" icon="play">Watch the 2-min demo</Button>
```

Hover lifts 2px and darkens; press scales to 0.985. Never put two `accent` buttons in one view.
