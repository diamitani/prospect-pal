# Prospect PAL Explainer Video

## Intent

Create a 45-second animated explainer showing how Prospect PAL transforms natural language campaign descriptions into deployable n8n/Make workflows. The video reinforces the "agent copilot" positioning — PAL is a builder/compiler, not a black box you rent.

**Core message:** What if building outbound automation was as simple as describing it?

## Story Arc (5-beat structure)

| Beat | Duration | Message | Visual Direction |
|------|----------|---------|------------------|
| Hook | 5s | "What if building outbound automation was as simple as describing it?" | Text reveal, attention grab |
| Problem | 8s | Most SDR tools are black boxes — you rent, you don't own | Split comparison: opaque box vs transparent |
| Solution | 15s | PAL compiles your intent into a real workflow | Animated flow: text input → processing → nodes appear |
| Proof | 12s | 9 deterministic nodes. Your keys. Your instance. | Pipeline building itself, node by node |
| CTA | 5s | Start building → prospectpal.dev | Logo lockup, URL |

## Customizations

### Visual Style
- **Light mode** — white/clean background, NOT dark mode
- Professional SaaS aesthetic (Linear, Notion, Vercel style)
- High contrast text for readability
- Subtle accent colors: cobalt blue from Prospect PAL brand
- Minimal visual noise, clean typography

### Voice
- Male TTS voice
- Professional but warm and upbeat
- Approachable, psychology-friendly tone
- Not robotic or overly technical

### Music
- Light, optimistic, subtle electronic
- Not aggressive "tech startup" music
- Soft SFX: node connection sounds, subtle compilation clicks
